Run MAIN.X68 to start the game. (Project -> Assemble source in Easy68k, then Execute, then F9)

Use left and right arrow keys for moving, up arrow key for inverting gravity.

Saving the inklings is optional, the goal is to escape the maze.

CONST.X68 contains the x and y coordinates of the initial level
(MAPSCRIX and MAPSCRIY, PYRXINI and PYRYINI for player coordinates within screen)
may be modified for debugging.
